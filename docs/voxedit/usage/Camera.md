# Camera

![voxedit-camera](../../img/voxedit-camera.png)

Allow you to create camera nodes and modify the current camera values.

Camera nodes are saved views. **Add new camera** stores the current viewport (position, orbit target, FOV, and Target/Eye movement). While that camera node is selected, orbiting the viewport updates the node. Click the camera in the scene tree (or **Use this camera** / the eye button) to restore its saved view.

To store a new shot on an existing camera, select that camera first, then move the view. Framing a shot while a model node is selected does not change any camera node.

[Animating](Animations.md) cameras is also possible to fly through your scene.
